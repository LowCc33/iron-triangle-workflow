# 铁三角多AI协作总规则 V1.0（示例版）

## 核心原则
1. Git是唯一状态总线，所有状态必须落地成文件
2. 文件优先级 > AI记忆，规则冲突以文件为准
3. 每个任务只能被一个Agent认领，防止竞争
4. 任务完成必须生成回执，老大确认后才算闭环

## 工作流程
1. 老大在 pending/ 目录下放任务文件
2. watcher自动检测，分配给对应Agent
3. Agent认领后移到 running/，开始执行
4. 执行完成移到 done/，生成回执到 receipts/
5. 老大验收，不满意打回 rejected/，满意则闭环

## 分工规则
- 🎯 老大：只提需求 + 验收，不参与技术细节
- ⚔️ 大将军：负责代码开发，具体实现
- 🧠 军师：负责架构审核，方案设计
