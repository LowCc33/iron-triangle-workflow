Iron Triangle Workflow - 铁三角多Agent协同开发工作流
🎯 项目定位
专为转行AI应用开发者设计的全自动协同开发系统，实现：
用户只负责提需求和验收，中间零思考、零记忆负担
多个AI Agent通过Git文件自动协作，100%可靠
彻底解决Agent记忆不可靠、消息丢包、状态不一致等行业痛点
⚡ 核心优势
特性传统Agent方案铁三角工作流
可靠性	依赖LLM记忆，概率性丢包	100%文件驱动，Git唯一状态总线
状态一致性	会话隔离，状态混乱	6目录状态机，全局唯一状态
幂等性	重复执行副作用	幂等性校验，重复执行不影响
规则生效	容易忘记规则	自动注入规则，文件优先级>AI记忆
🏗️ 架构设计
铁三角分工：
├── 🎯 老大（用户）- 只提需求 + 验收
├── ⚔️ 大将军 - 代码开发
└── 🧠 军师 - 架构审核 + 方案设计

6目录状态机：
├── pending/    - 待执行任务
├── running/    - 执行中任务
├── done/       - 已完成任务
├── rejected/   - 被驳回任务
├── receipts/   - 回执确认
└── alarms/     - 异常告警
🛠️ 核心模块
watcher调度器：每分钟轮询，自动检测新任务并分配
规则注入引擎：自动将总规则、代码规范注入每个任务最前端
幂等性校验模块：防止任务重复执行
Git缓存修复机制：解决WSL2跨系统文件缓存问题
双轨兜底机制：全自动 + 手动触发，永不掉线
